# 模块计划 04 — 完整前端（Day 10-12）

**前置**：P2 已交付可玩的最小客户端（脚手架、`useGame` hook、两步交互、`legal_actions` 高亮）。本阶段是在那个能跑的骨架上做加法，不是从零搭界面。

## 1. 本阶段新增内容

| 新增 | 说明 |
|------|------|
| 落点预览 | hover 合法备料行时虚影显示：放入几块 / 溢出几块到罚分行 / 罚分变化。**本类游戏"数手感"的关键辅助**，复用 CLI 的同一套计算逻辑（后端 `legal_actions` 携带 `overflow`、`penalty_delta` 字段下发） |
| 事件动画 | 上格方块闪烁 + `+N` 飘字；罚分红色 `-N`；由 `events` 队列驱动 |
| 动作日志 | MoveLog 面板，消费 events，逐条可读（"P1 从 D2 取 3 黄 → 备料行 3，溢出 1"） |
| EvE 观战 | 播放/暂停/单步/速度滑块，对接 `eve_control` 消息 |
| 热座 PvP | 两块玩家板都可交互，按 `state.current` 决定哪块激活 |
| 终局弹窗 | 终局加分明细（横行/竖列/同色各得多少）、胜负、再来一局 |
| SetupScreen | 完整模式与难度选择、seed 输入 |
| 剩余料统计 | TopBar 显示袋/弃料盒各色计数（公开信息，帮助玩家算牌） |
| 非法原因提示 | 非法目标行 hover 显示原因（"网格该行已有此色" / "该行已锁定其他颜色"） |
| 视觉打磨 | 见第 3 节 |

## 2. 最终组件树

```
App
├── SetupScreen                 # 模式（PvP热座/PvE/EvE）、AI 难度、seed、开始
└── GameScreen
    ├── TopBar                  # 轮数、当前行动方、比分、剩余料统计
    ├── DisplayArea             # 5 展台环形排列 + 中央池（含先手标记）
    │   └── TileGroup           # 可点击的同色组
    ├── BoardsRow
    │   └── PlayerBoard ×2
    │       ├── StagingRows     # 5 行，合法目标高亮 / 非法置灰 / 落点预览
    │       ├── Grid            # 5×5，底色淡显固定色位，已结算实色
    │       └── PenaltyRow      # 7 槽 + 罚分标注
    ├── SidePanel
    │   ├── MoveLog
    │   └── EveControls         # 仅 EvE
    └── GameOverModal
```

## 3. 视觉规范

- 桌面/平板优先，最小宽度 1024px；窄屏降级为玩家板纵向堆叠，不专门做手机适配。
- 色板：blue `#3B82F6`、yellow `#F5C542`、red `#DC4C41`、black `#3A3A46`、white `#F3EEE4`（描边区分白料与空格）。**色盲辅助**：每色方块带小图标纹样。
- 网格空位以 12% 不透明度显示该格应放的颜色，直观提示色位规律。
- 先手标记：中央池中独立圆形 token；被取走后显示在持有者罚分行首槽。
- 动画克制：CSS transition 为主，单个事件 ≤ 300ms，事件队列串行播放并可被"跳过动画"开关关闭（EvE 高速观战时必须能关）。

## 4. 测试
